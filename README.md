## 🌟 Overview

Welcome to the official repository of my personal developer portfolio! I'm **Kandati Ranjith Kumar Reddy**, a Computer Science graduate passionate about crafting full-stack applications with **MERN**, **Angular**, and **TypeScript**. 

This portfolio showcases my technical skills, featured real-world projects, work experience, and educational background in a clean, highly accessible, and visually stunning web application.

## ✨ Features & Highlights

- 🚀 **Powered by TanStack Start & Vite**: Lightning-fast SSR/SSG capabilities with full TypeScript type safety and file-based routing.
- 🎨 **Warm Stone & Neon Teal Color System**: Tailored dual theme (Light & Dark) using modern CSS custom properties and WCAG AAA contrast ratios.
- 💫 **Smooth Motion & Micro-Interactions**: Built using **Framer Motion (`motion`)** and **Lenis** smooth scrolling for liquid-smooth transitions.
- 📱 **Fully Responsive Layout**: Built with Tailwind CSS v4 and Radix UI primitives for headless, accessible UI elements.
- 🗂️ **Interactive Project Showcase**: Live links, GitHub repositories, and tech stack badges for featured full-stack projects.
- 📊 **Dynamic Skills & Experience Timeline**: Categorized technical skill cards and interactive career milestone timeline.
- 💌 **Integrated Contact Form**: Clean form validation with `react-hook-form` and `zod`.

## 🚀 Getting Started

Follow these steps to set up and run the portfolio locally on your machine.

### **Prerequisites**
- **Node.js**: `v18.0.0` or higher
- **npm** or **bun** / **yarn**

### **Installation**

1. **Clone the repository:**
   ```bash
   git clone https://github.com/KandatiRanjithKumarReddy/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or using Bun
   bun install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:3000`.
