## 🚀 Featured Projects

### 1. Borrower Copilot – AI-Powered Loan Affordability Platform

A financial web application that helps users understand how much loan they can safely afford based on their income and monthly expenses.

**Key Features:**
- Calculates safe borrowing limits based on income and expenses.
- Evaluates affordability using different borrowing percentages (25%–55%).
- Simulates financial situations where income drops by 15%.
- Integrates Google Gemini AI to generate financial insights.
- Includes backup AI models for improved reliability.
- Stores user profiles and loan information in MySQL.
- Supports Google Sign-In authentication.

**Technology Stack:**

React 19, TypeScript, Node.js, Express.js, MySQL, Google Gemini AI, Tailwind CSS, Vercel.
